# 四合一数据工具站 / Data Tools Hub

单文件静态网站原型：聪明钱雷达、组合实验室、宏观看板、AI 数据智库，四个研究工具合在一个页面里，无构建步骤、无外部 JS 库，图表用原生 canvas 手绘。

灵感来源：X 用户 @Karl4456 转推荐的 Jovian Research 四个免费工具（https://x.com/karl4456/status/2124353655931592719?a=ISkQhlMkk-e60-l-uQo&s=46），本站为同功能的原创重做版，界面与文案全部原创，不使用原站品牌、截图、文字、私有数据库或访问码内容。

## 四个模块

1. **聪明钱雷达**：公开可查的 13F 机构目录（Berkshire Hathaway、Pershing Square、Himalaya Capital），含 CIK 与 SEC EDGAR 13F 搜索直达链接；持仓数字为带日期与来源的快照（第三方整理自 SEC 13F，须以 SEC 原文为准），不是当前持仓；股票代码反查只在快照范围内生效，范围外明确提示未覆盖。A 股部分只写结构说明，不伪造投资者名单与持仓数字。
2. **组合实验室**：先尝试用浏览器 fetch 拉取 Stooq 日线 CSV 做真实回测与优化（等权、最小方差、最大夏普、风险平价近似，协方差与求解在 JS 里真实计算）；拉不到时显示错误与重试，并提供上传 CSV（date,close / 多列）与示例测算两种路径，示例数据全程标注“示例数据，非实时行情”。
3. **宏观看板**：用浏览器 fetch 拉取世界银行公开 API（无 Key），展示中国、美国、日本、欧盟的 CPI、GDP 增速、失业率最新值与年份、迷你折线；尝试拉取 FRED fredgraph.csv（DGS10、DGS2、FEDFUNDS），拉不到即显示未接入说明，不编数字；美联储利率预期不冒充 CME FedWatch 隐含概率。
4. **AI 数据智库**：用浏览器 fetch 拉取 OpenRouter 公开模型列表（无 Key），可搜索、可排序的价格表（每百万 token 价）；数据集卡片只写一句话原创说明加官方链接，不复制数据、不编芯片价格与开支数字；附公开 API 示例代码与通用 MCP 配置模板。

## 诚实标注原则

- 拉不到数据就显示错误状态加重试，绝不拿假数、示例数冒充实时数。
- 示例数据、快照数据必须明确标注日期、来源与“示例 / 快照”字样。
- 每个模块都标注数据截至与来源、拉取时间。

## 本地打开

```bash
cd data-tools-hub
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

也可以直接双击打开 `index.html`，但部分浏览器对 `file://` 下的跨域 fetch 限制更严，建议用上面本地服务方式打开。
