先说清楚：这个站能做什么、不能做什么

本站是同功能重做版原型，界面与文案均为原创。它不复制任何私有数据库，不使用访问码，不爬取受限内容。每个模块都当场拉取公开接口；拉不到就显示错误状态和重试，绝不拿示例数冒充实时数。

聪明钱雷达 13F 目录 + 快照

13F 是美国大型机构管理人每季度向 SEC 申报的持仓表，只含季度末的美国上市证券多头，不含空头、现金、债券与大部分非美持仓，且申报滞后最长 45 天。本页目录只列公开可查的机构；持仓列是快照，不是当前持仓。

股票代码反查（仅快照范围）

输入一只股票代码，查看它是否出现在下方快照里、被哪家机构持有。快照范围很小，范围外不代表没有机构持有。

反查只覆盖“持仓快照”里列出的持仓。未覆盖时页面会明确说“本快照未覆盖”，并给出 SEC 搜索链接，请自行到 SEC 核实最新 13F。

A 股结构说明 不伪造数据

A 股没有与美国 13F 对等的、免费公开的全量接口：公募基金持仓按季度在基金季报中披露，散户与“国家队”的完整名单并不存在一个统一的免费实时数据库；十大股东 / 十大流通股东数据分散在各公司定期报告中，且口径与时点各不相同。

因此本页不展示所谓“1.1 万投资者”名单，也不编造任何 A 股持仓数字。如需研究 A 股机构动向，请按公司查定期报告与基金季报原文，或使用持牌数据终端。本页只保留结构说明，避免用拼凑数字误导判断。

类别筛选选“A 股结构说明”时，本卡片会单独高亮；其他类别下它始终可见，作为口径提醒。

来源标注：SEC EDGAR 搜索链接由 CIK 生成；快照数字的日期与第三方整理来源见各机构卡片内，须以 SEC 原文为准。

上传 CSV（date,close 或多列）

两种格式都支持：① 单资产文件，表头为 date,close，会作为当前勾选的第一只资产；② 多资产文件，第一列为 date，其余每列列名为资产代码，值为收盘价。日期格式 YYYY-MM-DD。

上传文件只在浏览器本地解析，不会上传到任何服务器。

公开 API 示例（OpenRouter 公开接口，不是任何私有站点的 API）

fetch("https://openrouter.ai/api/v1/models")
  .then(function (r) { if (!r.ok) throw new Error("HTTP " + r.status); return r.json(); })
  .then(function (j) {
    // j.data 是模型数组；每项含 id、context_length、
    // pricing.prompt / pricing.completion（每 token 美元价）
    console.log("模型总数：", j.data.length);
    console.log(j.data[0].id, j.data[0].pricing);
  })
  .catch(function (e) { console.error("拉取失败：", e); });

通用 MCP 配置模板（需替换为你实际的 MCP 服务地址）

{
  "mcpServers": {
    "example-data-mcp": {
      "url": "https://example.invalid/mcp",
      "transport": "streamable-http"
    }
  }
}

说明：上面是通用 MCP 客户端配置模板，不是 OpenRouter 的 MCP 地址，也不代表本页已接入任何 MCP 服务。把 url 换成你自己部署或授权的 MCP 服务地址后，方可使用；不要把密钥写进公开网页。
